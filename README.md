# 自动收获

适用于《我的世界》（Minecraft）的自动收割模组。

> ⚠️ **注意**：由于精力有限，新功能与内容仅在**最新版本**中加入；旧版本仅进行 Bug 修复，不再添加新特性。

## 用法

- 按下 **`H`** 键开启或关闭模组功能。
- 默认启用 **种植模式**。

## 模式说明


| 模式         | 指令                         | 功能描述                                               |
|--------------|------------------------------|--------------------------------------------------------|
| **种植模式** | `/autoharvest mode plant`    | 自动种植手中的农作物（如小麦种子、胡萝卜等）到空耕地。 |
| **收割模式** | `/autoharvest mode harvest`  | 自动收割已成熟的农作物。                               |
| **除草模式** | `/autoharvest mode weed`     | 自动清理耕地上的杂草（如草、高草等）。                 |
| **喂食模式** | `/autoharvest mode feed`     | 自动对可繁殖动物使用食物，触发繁殖行为。               |
| **锄地模式** | `/autoharvest mode hoe`      | 自动将水源附近的草方块或泥土变为耕地。                 |
| **钓鱼模式** | `/autoharvest mode fishing`  | 自动投掷鱼竿并收杆，实现全自动钓鱼。                   |
| **催熟模式** | `/autoharvest mode bonemeal` | 自动对未成熟的农作物使用骨粉进行催熟。                 |
| **农夫模式** | `/autoharvest mode farmer`   | 结合收割与种植：自动收割成熟作物并立即重新种植。       |

> 💡 **提示**：切换模式后，模组将会自动变为 **开启状态**（按 `H` 切换开启或关闭状态）

## 26.2 分支配置

- **范围来源 `rangeSource`**：默认 `CUSTOM`，继续使用现有 `radiusCenti`（10–65，表示 1–6.5 格），不重置旧配置。选择 `PLAYER_ATTRIBUTE` 后，方块交互实时读取玩家的 `blockInteractionRange()`，喂食/剪羊毛读取 `entityInteractionRange()`，包含装备、效果等属性修饰。使用原版范围判断，不额外套用自定义半径或隐藏上限；客户端无法绕过服务器规则。
- **单 tick 最大操作数 `maxActionsPerTick`**：1–64，默认 1。`ticksPerAction` 仍控制两批操作的间隔，每个执行 tick 使用一次扫描处理多个不同目标。预算统计已发送的交互尝试，不保证服务器接受；农夫模式收割和补种共享预算（默认 1 时分不同 tick 完成）。补给/切换物品不计为世界交互。时运工具切换仍延迟到下一次执行，钓鱼状态机与收杆/抛竿间隔不加速。
- **交互时挥手 `swingHand`**：默认关闭。启用时遵循原版交互结果，以实际主手/副手调用原版挥手，其他玩家可正常看到。无重复自制动画包；无法屏蔽服务器自行触发的动画。喂食原有的无条件挥手也改为受此开关控制。

### 性能与验证

扫描去除了每格中心向量分配和重复的锄地扫描，水检测复用可变坐标与方块状态，并包含上游 a92220ec 的修复：检测同层和上一层的水。属性范围较大时，每次最多检查 4,096 个候选格，后续执行 tick 继续扫描，直到覆盖完整范围；普通移动保留扫描进度，并按当前位置过滤；扫描完成、大幅位移（超过扫描直径）、切换世界或修改范围后重新开始，因此不会为大范围一次扫描整个立方体。农夫补种队列有数量、重试与过期限制，避免长期积累。客户端出现幼苗后继续观察 40 tick，以便回滚为空气时重试，这只是有限的预测宽限期，不是服务器确认。未完成的补种最多保留 1,200 tick；512 项队列满时暂停新的需补种收割。
